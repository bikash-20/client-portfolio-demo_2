# High-End Interactive Portfolio Platform

Pure HTML, CSS, and vanilla JavaScript portfolio site built as an independent academic term project.

## What it includes

- Split static scaffold with `index.html`, `styles.css`, and `script.js`
- Native cursor tracking, scroll progress, reveal effects, and modal handling
- Glassmorphism panels, gradient motion, and layered visual styling
- Minimal npm metadata for local preview and simple repository setup

## Project files

- `index.html` - semantic page structure and asset wiring
- `styles.css` - token system, layout, motion, and responsive rules
- `script.js` - interaction logic and animation behavior
- `read.md` - detailed academic/project write-up
- `package.json` - local preview scripts
- `package-lock.json` - locked scaffold metadata

## Local preview

```bash
npm run start
```
